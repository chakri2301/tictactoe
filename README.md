#### TicTacToe game 
### Implemented features
1. Basic game
2. Impossible Bot added
3. Games can be saved by Save And Exit button
4. Saved Games can be located at Load Game screen
### To be implemented

# live Game can be played at [https://chakri2301.github.io/tictactoe/](https://chakri2301.github.io/tictactoe/)

```bash
git clone https://github.com/chakri2301/tictactoe.git
cd tictactoe
npm install
npm run dev
```
